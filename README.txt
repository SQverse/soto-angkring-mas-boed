# Soto Angkring Mas Boed — Website

## Struktur
- `index.html` — full responsive website
- `assets/images/` — gambar yang sudah di-upscale dan di-sharpen
- `assets/music/` — tempat file musik latar

## Musik
Letakkan file musik dengan nama persis:
`Soto Mas Boed, Bikin Kangen.mpeg`

di:
`assets/music/Soto Mas Boed, Bikin Kangen.mpeg`

Autoplay dengan suara bergantung pada kebijakan browser. Kode sudah mencoba autoplay saat halaman dibuka dan otomatis menyediakan fallback: interaksi pertama pengguna akan menyalakan musik jika autoplay bersuara diblokir. Controller fixed di kiri bawah menyediakan Play/Pause.
